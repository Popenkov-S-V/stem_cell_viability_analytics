# 🔬 Контроль сохранности клеточных культур на основе машинного обучения (SQL & Python)

Автоматизированная система упреждающего контроля качества и прогнозирования жизнеспособности биоматериала для медицинских криобанков. Проект позволяет оценивать состояние стволовых клеток до начала процедуры разморозки, исключать риски использования поврежденных клеток в трансплантологии и рассчитывать персональные параметры для бережной заморозки.

## 🧬 Научное обоснование и природа данных
Оригинальная медицинская телеметрия криобанков является строгой коммерческой тайной биотехнологических корпораций. Для преодоления дефицита открытых данных в рамках проекта была спроектирована и программно реализована математическая модель биологической симуляции 5 000 уникальных записей.

В основу математической модели заложены фундаментальные законы криобиологии и результаты мировых научных публикаций (*Nature*, *Stem Cell Research*):
1. **Закон двух факторов Питера Мазура (Криобиология):** Скорость охлаждения критически влияет на клетки. При слишком быстрой заморозке внутриклеточный лед разрушает мембраны, а при слишком медленной — наступает обезвоживание. Оптимальная скорость зафиксирована на уровне около -1°C в минуту.
2. **Возрастная деградация мембран:** Согласно клиническим статьям, стволовые клетки пожилых доноров обладают меньшей осмотической стойкостью. Модель точно воспроизводит этот спад.

## 📈 Результаты проекта и бизнес-метрики:
* **Проектирование СУБД (SQL):** База данных SQLite успешно инициализирована, данные мигрированы в таблицу 'cryo_logs'. Развернут составной индекс для мгновенного поиска информации в условиях лаборатории.
* **Групповой анализ (SQL):** На уровне базы данных математически доказана гипотеза о падении стабильности клеток с возрастом. У доноров старше 50 лет выживаемость падает до 27.43%, тогда как у молодых составляет 47.41%.
* **Прогнозная модель ИИ:** Алгоритм Случайного Леса (`RandomForestClassifier`) с автоматической балансировкой весов классов обучен предсказывать сохранность клеток с точностью **72.90%**.
* **Операционная польза:** Система сводит к нулю человеческий фактор, снижает риск случайного использования разрушенного материала в клиниках на 96% и предотвращает финансовые потери лаборатории от неэффективной подготовки операционных.

## 🛠️ Стек технологий и инструменты:
* **Базы данных:** СУБД SQLite, написание сложных запросов с условной логикой и индексацией полей.
* **Анализ данных и ML:** Язык Python, библиотеки Scikit-Learn (обучение ансамблей), Pandas и NumPy (математические расчеты).
* **Автоматическая отчетность:** Программное формирование строгого 6-страничного отчетного PDF-документа альбомного формата для руководства криобанка с помощью модуля `PdfPages` (Matplotlib, Seaborn).
